# ADR-013: 平面锁定、绳连接碰撞与气球运行时参数（试玩验收三项）

## 状态

Accepted。修正 ADR-009 决策 5（接触过滤范围）、ADR-011 偏差 3（气球机身参数未采纳）、ADR-005「原作是 2.5D」的落地方式。

## 日期

2026-10-03

## 背景

试玩报告三处与原版不符：

1. **气球拉力偏大**（摆动正常，拉力偏大）。
2. **沙袋没有碰撞箱**。
3. **断裂后出现平面外旋转**（车从中间断开后两个半截发生 3D 旋转，2.5D 丢失）。

调查（真实 Bepu + 真实沙盒房间；复现脚本 `tasks/probe-playtest/`，验收后删除）：

- 气球：原版把 `m_force`（prefab 11.5）× `BalloonForce`（`INSettingsBExp.json` 2.0）= **23 N** 每 `FixedUpdate` 施加到**气球自身刚体**上（`Balloon.cs:207-210`），并把该刚体改写成 `mass 0.1`、`linearDamping 2`、`angularDamping 0.5`、`constraints 48`（`Balloon.cs:129-132`），因此原版的升力加速度是 **230 m/s²**。PigForge 的 `content/parts.json` 原为 `mass 0.3` + `balloon 1.5`，`RunBalloons` 把 `LiftPerTick` 当**冲量**施加：Δv = 1.5 / 0.3 = **5 m/s/tick = 300 m/s²**，等效持续力 90 N —— 对整机的拉力约为原版 23 N 的 **3.9 倍**（实测整机被拽起的加速度 59 m/s² 对原版 11 m/s²）。
- 沙袋 / 平面外旋转：`BepuPhysicsWorld` 对所有 PigForge 关节登记 `_jointedPairs`，`AllowContactGeneration` 拒绝该对的接触。运行时绳（`PhysicsJointKind.Distance`，气球绳/沙袋绳）因此与其锚点**永不碰撞**；同时 PigForge 从未实现原版的「每刚体冻结 Z 位移与 X/Y 旋转」（`RigidbodyConstraints` 56 = `Sandbag.cs:135`、`Pig.cs:235`；48 = `Balloon.cs:132`）。两者叠加后：绳是 3D 摆，没有恢复平面的任何机制。实测 240 tick 的「木框 + 沙袋」场景，沙袋漂到 **z = 1.10 m**、姿态 `(0.090, -0.632, 0.663, 0.392)`（≈ 4D 翻滚），木框也被拖到 z = 0.31、qx = -0.010；裂缝拆分只是把这种漂移换成两个半边各自漂移（用户看到的「平面外旋转」）。

## 原版真值（逐条出处）

1. `Balloon.cs:7` `m_force` 默认 10；`Part_Balloon_01_SET.prefab:100` 序列化 11.5；`Balloon.cs:181` `m_force *= INSettings.GetFloat(INFeature.BalloonForce)`（`INSettingsBExp.json:456` = 2.0）→ 单气球 **23 N**。
2. `Balloon.cs:112-120` 多气球是**克隆出的独立刚体**（`Part_Balloons2/3` 每只气球都有自己的 23 N）。
3. `Balloon.cs:129-132` 运行时改写：`mass 0.1f`、`linearDamping 2f`、`angularDamping 0.5f`、`constraints (RigidbodyConstraints)48`（= `FreezeRotationX | FreezeRotationY`）。
4. `Balloon.cs:207-210` `FixedUpdate`：`rigidbody.AddForce(m_force * m_direction, ForceMode.Force)`，作用点即刚体质心。
5. `Sandbag.cs:135` `constraints = 56`（= `FreezePositionZ | FreezeRotationX | FreezeRotationY`）、`Sandbag.cs:133-134` `linearDamping 1f`、`angularDamping 10f`；`Pig.cs:235` 猪同样是 56。
6. 沙袋/气球的运行绳都是 `SpringJoint`（`Sandbag.cs:140-164`、`Balloon.cs:150-160`），**没有任何 `Physics.IgnoreCollision`**；只有框包裹件会忽略碰撞（`Frame.cs:52-66`）。
7. 原版另有 `RigidbodyRotationConstraints`（被锁轴在 `LateUpdate` 里被**写回起始值**）：被冻结的自由度不是靠求解器"希望"它为零，而是每帧被硬性修正。

## 决策

1. **每刚体冻结自由度进入物理契约**：`BodyDefinition.Constraints`（`PhysicsConstraintMask`）声明该刚体**永不积分**的自由度。Bepu 后端两处落地：
   - `PoseIntegratorCallbacks.IntegrateVelocity`：积分前把被冻的分量速度清零（求解器这一步写进去的角速度/线速度不会进入姿态积分）；
   - `Step` 之后的 `ApplyFrozenDegreesOfFreedom`：把被冻轴写回**创建时的值**（Z 位移 = 创建时的 Z；被冻旋转轴的姿态分量 = 0 并重新归一化）。这一步对应原版 `RigidbodyRotationConstraints` 的硬修正，让「平面外旋转」在数值上恒为 0（实测 240 tick 后沙袋 z = 0.000000、ω_x = ω_y = 0.00000）。
   未声明约束的刚体（物理契约测试、回放路径）行为完全不变。
2. **房间给每个权威刚体加 2.5D 锁**：`GameRoom.PlanarConstraintMask = LockPositionZ | LockRotationX | LockRotationY`（即原版的 56），在**所有**建体入口传入（`Start` / `StartPlayer` / `MaterializeLevelActors` / `SplitFromAppliedCommands` / `DetachFromCompound`）。裂缝拆分走同一条 `CompoundCluster.CreateBodyDefinition`，因此**拆分出来的新刚体自动继承该锁**。Z 自转（滚动、摆锤）与 X/Y 平移不受影响。
3. **接触抑制只保留铰链对**：`_jointedPairs` 现在只在 `PhysicsJointKind.Revolute`（轮子铰链，ADR-009：轮胎球与挂在父体上的支撑盒故意重叠）时登记。运行绳（`Distance`）不再抑制接触 —— 与原版一致：沙袋/气球会撞到它所系住的零件，框包裹件因为合一刚体天然不碰撞。ADR-009 决策 5 相应收窄。
4. **气球采用原版运行时参数**：`tools/bple-lift/`（新增 extract + apply，报告驱动、幂等）把每只气球的 `mass 0.1`（`Balloon.cs:129`）与升力冲量 `m_force × BalloonForce / 60` 写进 24 条气球族内容（基础 3 + 变体 21）；容器 60 Hz 下每 tick 施加一次冲量，故 `capabilities.balloon` = 力/60 = 0.383333 / 0.766667 / 1.15（单/双/三）。此时 Δv = 3.8333 m/s/tick，即**原版的 23 N / 0.1 kg = 230 m/s²**，整机受到的持续拉力回到 23 N 量级（实测整机加速度 11 m/s² 对原版同量级）。
5. **旋翼（rotor，37/184-192）保持原值不动**：它是 PigForge 自造的「气球式升力 + 放气」偏差（`docs/original-vs-implemented.md`），不是原版气球族；本 ADR 的单位变更不适用于它，apply 工具会把它列为「无气球 prefab 的 balloon 能力件」并跳过。
6. **分离器角色补登记**：`RegisterPlacedRole` 从未调用 `_rules.AddDetacher`，`RunDetachers` 因此永远空转、分离器零件（43）完全无效。补上 `capabilities.IsDetacher → _rules.AddDetacher(entity)`，让「触发 → 在最近的缝上拆出自己」（`GameRoom.DetachFromCompound`）真正可用，也是本 ADR 拆分验收的确定性入口。

## 记录在案的偏差

1. **阻尼未建模**：原版气球 `linearDamping 2` / `angularDamping 0.5`、沙袋 `1` / `10` 仍无对应实现（物理契约没有每刚体阻尼）。它是二阶瞬态（气球被绳拉住、沙袋靠 2.5D 锁与接触收敛），本轮的实测差异不在阻尼；若后续手感需要，需在 `BodyDefinition` 增阻尼字段并在位姿积分器里按 `v /= 1 + dt·c`（Unity 模型）实现，并扩展内容 schema/parser。
2. **气球的 Z 位移也被锁**：原版气球只锁 X/Y 旋转（48），PigForge 统一锁 56。气球是球体、绳锚点在平面内，Z 上本无力，行为差异不可观测；统一锁让「任何权威刚体都不离开平面」成为单一不变量。
3. **`Sound/破泡/随机绳长/BalloonBalancer`** 仍缺失（ADR-011 偏差 1/2/4 不变）。

## 验证

- **`dotnet test PigForge.slnx`（Debug）：349 通过 / 0 失败**（Protocol 39、Core 174、Replay 11、Physics 32、Server 93）。新增 6 条 + 修正 1 条既有：
  - `PigForge.Physics.Tests/PlanarConstraintTests`（2）：掩码冻结 Z 与 X/Y 旋转、对照体必须飞出平面；带 1 cm 平面外绳锚点的绳对在 600 tick 摆动中逐帧 z/qx/qy/ωx/ωy **恒等于 0**。
  - `PigForge.Physics.Tests/JointedContactTests`（2）：绳对接触**必须**产生（改动前为 0 次）；铰链对**必须**不产生。
  - `PigForge.Server.Tests/PlanarStabilityTests`（3）：木框+木框+分离器+沙袋的机器落地后触发分离器 → 刚体数由 1 变 2（块与分离器分离），随后 360 tick 内**所有**实体 z/qx/qy/ωx/ωy 恒为 0；同脚本双跑 `ComputeStateHash()` 相等；木框+沙袋+气球的三绳场景 400 tick 后仍然逐体恒 0。
  - `PigForge.Server.Tests/BalloonLiftTests`（3）：自由气球逐 tick 加速度 = 230 − g ≈ 220.19 m/s²（原版 `23 / 0.1`，容差 0.5）；单气球拉 1 kg 木框 1 秒的上升量在 (0.2, 4) m 内（改动前 90 N 等效会把它拽到 ~30 m）；沙袋从 12 格外落下后停在地形上、全程不陷入地面板块、z 恒 0。
  - `PhysicsContractTests.BepuWorldDistanceJointHoldsTheRopeBand` 改为小半径球：绳对现在会碰撞（原版 SpringJoint 不忽略），所以该测试只验证「绳带」本身，避免 0.5 半宽的盒子在带内必然接触。
- 内容：`node tools/bple-lift/extract-lift.mjs` 报告 24 条气球族（23 N、0.1/0.2/0.3 kg、0.383333/0.766667/1.15），`apply-lift.mjs` 幂等（二次运行无改动）、逐条断言写入值等于报告值；`clients/web/src/builder/playParts.generated.json` 同步再生成，`pnpm test` 198 通过（含 `slope.test.ts` 漂移守卫）、`pnpm build` 通过。
- 试玩复现（真实沙盒，改动前后对比，`tasks/probe-playtest/`）：
  - 气球自由上升 Δv 4.8365 → 3.6698 m/s/tick（= 290 → 220 m/s²）。
  - 木框+沙袋 240 tick：沙袋 z 1.100 → **0.000000**、姿态 (0.090,-0.632,0.663,0.392) → **(0,0,0.975,0.224)**（纯 Z 自转）；木框 z 0.127 → **0.000000**。
  - 把 `PlanarConstraintMask` 临时改回 `None` 复跑同一房间：沙袋立刻回到 z = 1.10、qx = 0.090（证明是掩码在起作用，不是别的改动）。
- 拆分路径实测（真实沙盒）：分离器触发后块 = body 12、分离器 = body 13（拆分生效），随后 360 tick 全部 z/qx/qy 恒 0。
