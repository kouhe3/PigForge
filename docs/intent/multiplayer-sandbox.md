# Intent: 多玩家持续沙盒（本机）

> 2026-09-09 访谈确认；2026-10-04 用户修订两条（零件不跨断连存活、RESET 保留布局，见 ADR-026）。后续 spec/计划消费本文件，不重新猜范围。

- **Outcome:** 本机启动服务器 + 多个浏览器客户端连入同一个持续运行的世界；每个玩家自由摆放零件（先是预览布局、他人可见），点 Start 才把自己的布局装配成物理体；世界物理从不暂停；RESET 只作用于该玩家自己、把他的零件放回 START 之前的布局（不用重新摆），其他人不受影响；玩家断开（socket 关闭）后其零件离开世界——连接就是玩家的生命。
- **User:** 仓库维护者本人 + 本机多开的玩家（多标签/多窗口），用于验证多人沙盒闭环。
- **Why now:** minimal-playable 单机闭环已完成；社群反馈第一优先级是「持续运行的世界 + 单人 RESET」，它一次性逼出多玩家身份、零件归属、预览/实体分离三块基础能力。
- **Success:** 两个客户端同时连入——A 摆放并 Start 后，B 能看到 A 的载具在跑、能撞到它；B 自己摆放时只有预览；A 按 RESET 后 A 的载具回到 START 之前的预览布局（A 可以直接再 Start），B 的载具与布局不受影响；A 关闭标签页/掉线后 A 的零件从世界里消失且不再占格；全程世界 tick 不停。
- **Constraint:** 权威只在服务器；客户端永不提交位姿/接触/断裂/胜负；loopback 多客户端、无账号；沿用 PGFS/PGFC 二进制线格式与确定性 tick 纪律（协议是否升版留给 spec）；沙盒无终局，`GameplayPhase` 的 Won/Failed 不适用，出界只影响该玩家自己。
- **Spec:** `docs/specs/multiplayer-sandbox.md`
- **Out of scope:** 地形编辑与平滑曲面、竞速与计时器排名、远程监听与鉴权、跨服务器重启持久化、多世界分房。
