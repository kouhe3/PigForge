# Intent: 最小能玩（本机 Web + Server）

> 2026-09-07 访谈确认。后续 spec/计划消费本文件，不重新猜范围。

- **Outcome:** 本机启动 Web 客户端与无头服务器，进入固定斜坡关：起点在坡顶、终点在坡底。玩家用鼠标自由放置、旋转（可斜）、缩放零件，点 Start 后猪沿坡滚入坡底目标区。
- **User:** 仓库维护者本人，本机自玩验收。
- **Why now:** Core / 协议 v2（自由角、缩放、复合体）已落地；缺的是可上手的建造→启动闭环，不是再扩模拟。
- **Success:** `server` 广播权威 tick + `pnpm dev` 能完成一局：斜着摆、缩放、Start，画面跟随服务器快照；进目标可见胜利，出界或超时可见失败。一次通关即可。
- **Constraint:** 第一刀不要 keep / 「第二辆车」。权威只在服务器。Web 只提交建造与 Start 命令，永不提交位姿、接触、断裂或胜负。零件库用现有 `content/parts.json` 子集。
- **Spec:** `docs/specs/minimal-playable.md`
- **Out of scope:** keep 再建造、客户端预测回滚、贴图与 M2 双回放差异、多关选择、账号与匹配、Unity 正式客户端、雕塑场景的关节/复合体调参。
