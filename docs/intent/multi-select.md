# Intent: 建造多选（框选）与 PGFA 错误语义（本机）

> 2026-09-09 用户口述：「给2选择 加拖拽框选」「AND 加错误代码语义给前端」。
> 默认决策（中键平移、中心点命中、批量删除/键盘、非原子）见规格 Assumptions；实现不得另猜。

- **Outcome:** 建造模式下用选择工具（快捷键 `2`）拖拽空白即框选多个零件，多选高亮、`Shift` 加选；`Delete`/方向键/`R` 作用于全部选中的自有可编辑零件。PGFA 拒绝回执在前端显示中文语义（如「位置已被其他零件占用」），而不是 `status=5 error=6`。
- **User:** 仓库维护者本人 + 本机多开的玩家（多标签/多窗口）。
- **Why now:** 摆大车时逐个点选/删除太慢；`advanced-building` 切片只做了单选 v1；错误码对使用者不可读。
- **Success:** 框选 3 个零件 → 3 个高亮 → `Delete` 一次删完；框选后按 `R` 全部旋转；重叠放置时错误列表显示「命令 N（放置零件）被拒绝：位置已被其他零件占用」。
- **Constraint:** 纯 Web（无协议/内容/服务端改动）；服务器仍是唯一权威，批量 = 每零件一条 PGFC 逐条校验、非原子；不引入客户端预测。
- **Spec:** `docs/specs/multi-select.md`
- **Out of scope:** 批量指针拖拽（多零件同屏预览）、footprint 精确框选、数值输入面板、复制/粘贴/镜像/对称、跨玩家选择他人零件做操作。
