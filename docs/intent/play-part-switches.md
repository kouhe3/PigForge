# Intent: PLAY 零件开关（本机）

> 2026-09-09 已确认（用户口述：原作靠画面中下方按钮或点零件；BPLE MOD 增加了按**类型**的热键，没有 Besiege 式单个零件热键）。
> 关键决策已拍板：PGFS v3 + `flags`、开关是唯一玩家触发、气球/旋翼 `trigger`（放气/摧毁）。规格：`docs/specs/play-part-switches.md`。

- **Outcome:** PLAY 沙盒里零件**默认不工作**；玩家用画面中下方的开关条（每个可开关零件类型一个按钮）、类型热键或直接点自己的零件，把零件**启动/停止**。开关状态由服务器持有并随快照下发，他人可见但不可操作。
- **User:** 仓库维护者本人 + 本机多开的玩家（多标签/多窗口）。
- **Why now:** 目前 Start 后发动机/风扇/气球/火箭**立刻生效**，玩家没有任何控制手段；沙盒少了原作最核心的交互（「点一下才动」），一次性零件也无法择机触发。
- **Success:** 两个标签：A Start 后载具静止；A 点「发动机」按钮（或按 `1`，或点发动机零件）→ 载具开动，再点 → 停；B 看到 A 的零件亮起但点它被服务器拒绝。火箭/礼花/风箱/抓钩/TNT 只有被开关触发才动作；气球 Start 后即提供升力，开关放气后消失。RESET 后重新 Start，所有开关回到关闭。
- **Constraint:** 权威只在服务器（客户端零预测）；沿用 60 Hz 确定性与 ADR-002（TNT/脱钩的**撞击**语义不变）；哪种零件有开关是**内容**（`content/parts.json`），不是代码常量；协议沿用追加式演进（PGFC 19B 头/v2 不变，PGFS 因需要 per-entity 状态升 v3）。
- **Spec:** `docs/specs/play-part-switches.md`
- **Out of scope:** Besiege 式单个零件热键绑定/自定义按键、开关组多选与框选、跨会话持久化、音效/动画、原作「发动机按钮联动所有动力零件」的特例（v1 每类型一个按钮）。
